# ✅ Rippling Data Accuracy & Integrity

Maintaining correct and up-to-date employee data in Rippling is a core responsibility of HR Operations. Inaccurate data leads to payroll errors, compliance issues, and incorrect reporting.

---

## 📋 Key Data Fields to Maintain

### Employee Profile
- [ ] First name / Last name — matches legal documents
- [ ] Job title — reflects current role
- [ ] Department / Business Unit — correct assignment
- [ ] Reporting line (Manager) — up to date
- [ ] Employment type (FTE / Contractor / Part-time)
- [ ] Location / Country / Jurisdiction
- [ ] Start date — accurate
- [ ] Employment status (Active / On Leave / Terminated)

### Compensation
- [ ] Base salary — current, post any approved changes
- [ ] Currency — matches employee's jurisdiction
- [ ] Pay frequency (monthly / bi-weekly / weekly)
- [ ] Bonus structure — updated after each cycle

### Compliance & Documents
- [ ] Signed employment contract on file
- [ ] Tax forms completed
- [ ] Bank details for payroll verified
- [ ] Work authorization / visa status (if applicable)

---

## 🔄 Regular Checks

### After Every Onboarding
- Verify all profile fields are filled in correctly
- Confirm contract is signed before start date
- Check department and reporting line match org chart

### After Every Offboarding
- Termination date is accurate
- Employment status set to Terminated
- Final pay correctly calculated

### After Salary Changes
- New salary amount and effective date entered correctly
- Old salary history preserved (do not overwrite)
- Change reflected in next payroll run

### After Org Changes (promotions, transfers, reorgs)
- Job title updated
- Department / BU updated
- Reporting line updated
- Level / grade updated if applicable

---

## 🗓 Periodic Audits

### Monthly
- [ ] Cross-check active headcount in Rippling vs actual headcount
- [ ] Verify no ghost employees (terminated but still active)
- [ ] Check for missing or incomplete profiles

### Quarterly
- [ ] Full data audit before bonus cycle
- [ ] Verify all compensation data is current
- [ ] Confirm all levels and job families are assigned

### Ad-hoc
- [ ] Correct errors flagged by Finance or managers
- [ ] Update data after legal name changes, relocations, role changes

---

## ⚠️ Common Errors to Watch

| Error | Impact | Fix |
|-------|--------|-----|
| Wrong jurisdiction | Tax errors, compliance risk | Update country/state immediately |
| Missing manager | Blocks approval workflows | Assign correct reporting line |
| Outdated job title | Wrong org chart, reporting issues | Update after each promotion/change |
| Salary not updated | Incorrect payroll | Update with correct effective date |
| Active status after termination | Payroll overpayment, security risk | Set to Terminated immediately |
| Wrong employment type | Benefits/tax miscalculation | Verify with contract |

---

## 📁 Source of Truth

All employee data in Rippling must match:
- Signed employment contracts
- Approved salary change requests
- Official org chart
- Finance-approved headcount plan
